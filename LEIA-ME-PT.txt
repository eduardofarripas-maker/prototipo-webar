PROTÓTIPO WEBAR — A ILUSTRAÇÃO GANHA VIDA
========================================

O QUE ESTE PROJETO FAZ
---------------------
Abre uma experiência WebAR no navegador do telemóvel. O MindAR reconhece a
ilustração através da câmara e apresenta pequenos elementos animados alinhados
com a imagem: estrelas flutuantes, pontos pulsantes, arcos e confettis.

NOTA SOBRE A ANIMAÇÃO
--------------------
Nesta primeira versão, a ilustração original permanece estática. Os elementos
AR sobrepostos é que se movimentam. Para articular braços, pernas e rostos das
personagens, será necessário criar uma animação separada das personagens.

PASSO 1 — GERAR O FICHEIRO target.mind
-------------------------------------
1. Abra o compilador oficial do MindAR:
   https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. Carregue assets/ilustracao.jpg.
3. Execute o processamento/compilação.
4. Descarregue o ficheiro .mind gerado.
5. Renomeie-o exatamente para target.mind.
6. Coloque-o na pasta assets deste projeto, ao lado de ilustracao.jpg.

O ficheiro target.mind é indispensável. Não é possível gerar este ficheiro
apenas mudando o nome da imagem: tem de ser produzido pelo compilador MindAR.

PASSO 2 — PUBLICAR NO GITHUB PAGES
----------------------------------
1. Crie uma conta em https://github.com/ (se ainda não tiver uma).
2. Crie um repositório PUBLICO, por exemplo: prototipo-webar.
3. Carregue o conteúdo desta pasta para a raiz do repositório:
   index.html, css/, js/, assets/ (incluindo target.mind).
4. No repositório, abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Escolha a branch main e a pasta / (root); carregue em Save.
7. Aguarde pela publicação. O endereço será semelhante a:
   https://SEU-UTILIZADOR.github.io/prototipo-webar/

PASSO 3 — TESTAR
----------------
1. Abra o endereço HTTPS num telemóvel.
2. Toque em “Iniciar experiência” e permita o acesso à câmara.
3. Aponte para a ilustração original (no ecrã de outro dispositivo ou impressa).
4. Mantenha a imagem bem iluminada e inteira dentro do enquadramento.

PASSO 4 — CRIAR O QR CODE
------------------------
Depois de confirmar que o endereço público funciona, crie um QR Code que
aponte para esse URL. Pode usar um gerador de QR Code estático. O QR Code
apenas abre a página; o reconhecimento da ilustração é feito pelo MindAR.

ESTRUTURA
---------
index.html             página da experiência
css/style.css          apresentação do ecrã inicial
js/ar.js               inicia a câmara e a experiência
assets/ilustracao.jpg  imagem de referência original
assets/target.mind     ficheiro a gerar no compilador MindAR

REQUISITOS E LIMITAÇÕES
----------------------
- A página tem de estar publicada em HTTPS para acesso à câmara.
- O utilizador não precisa de instalar uma aplicação, mas precisa de Internet.
- O utilizador tem de autorizar o acesso à câmara.
- Teste preferencialmente em Safari (iPhone) ou Chrome (Android).
- O desempenho depende do telemóvel, da luz e da qualidade do reconhecimento.
- As bibliotecas A-Frame e MindAR são carregadas de CDNs, por isso é necessária
  ligação à Internet também para carregar essas bibliotecas.
- O repositório GitHub Pages tem de ser público no plano gratuito.
